# Andalib Samandari's Personal Website

Personal website built with Hugo and deployed to GitHub Pages. It uses the
`verso` theme, which lives in this repo under `themes/verso/` (see
`themes/verso/README.md` for the theme's design and content schema).

## Prerequisites

- [Hugo extended](https://gohugo.io/installation/) v0.146.0 or later (CI builds
  with 0.161.0). The extended build is required for image resizing and CSS
  minification.
- Git

## Local Development

```bash
hugo server        # production view (drafts hidden)
hugo server -D     # includes drafts, e.g. the delusion-mitigation research entry
```

Visit http://localhost:1313 to see the site.

## Content

Content is Markdown with front matter under `content/`:

- `content/_index.md` — Home. The bio paragraphs are the page body; the news
  list is the `news` front matter. The Home "Selected" list is derived from the
  research entries (no need to hand-write it).
- `content/research/<slug>.md` — one file per research entry. Each entry sets
  `year`, `status`, `tier` (`selected` or `list`), and optional `links`; the
  filename becomes the `#slug` anchor. See `themes/verso/README.md` for the full
  schema.
- `content/research/_index.md` — configures the Research section (it is listed,
  never rendered as per-entry pages).

The Writing page is dormant at launch: the `writing` nav item points at
Substack. To enable an on-site Writing page and post list, follow the steps in
`themes/verso/README.md`.

### Site configuration
Edit `config.toml` for the site title, base URL, navigation menu, footer/contact
links, and the theme's design knobs under `[params.design]`.

### Images
The Home frontispiece is `static/images/me.jpg`. `static/images` is also mounted
into Hugo's asset pipeline (see `config.toml`) so it can be resized.

## Deploying

The site auto-deploys via GitHub Actions (`.github/workflows/hugo.yml`) on every
push to `main`:

```bash
git add .
git commit -m "Your commit message"
git push origin main
```

Monitor deployment: https://github.com/andalibmalit/andalibmalit.github.io/actions

## Notes

- Don't edit `public/` — it's generated by the build.
- Hugo version: CI is pinned to 0.161.0 (see `.github/workflows/hugo.yml`).
