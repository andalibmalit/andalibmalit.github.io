A first paragraph usually carries the claim. It should read at the same pace as the rest of the page, without a larger opening size or a drop cap, so the reader settles in rather than being announced to. Links inside prose, like this one, take the accent and a thin underline; nothing else on the page uses colour.

A section heading at body size

Headings inside a post are one weight heavier than the text and no larger. They separate ideas by position and a little extra space above, which is all a reader needs to find their place again after looking away.

A quotation is set at full size and simply indented. It keeps the roman; the italic is reserved for titles and emphasis, so it stays meaningful when it appears.

Figures, when a post needs them, take the full measure and sit between paragraphs with the same spacing as text. Numbers in running text use old-style figures — 788 scenarios, 67%, 96% agreement — so they sit on the line like words rather than shouting.1
